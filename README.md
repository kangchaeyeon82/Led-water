# Led-Water 💧

**물로 보는 LED 회로** — 9V 건전지, 저항, 빨간 LED로 이루어진 회로를 '물길'에 빗대어 보여 주는 인터랙티브 학습 페이지입니다.

눈에 보이지 않는 전기를 물탱크·좁은 관·물레방아로 바꿔서, 전압과 전류가 회로 안에서 어떻게 나뉘는지 애니메이션과 직접 조작으로 이해할 수 있게 만들었습니다.

## 비유 한눈에 보기

| 회로 | 물길 |
| --- | --- |
| 9V 건전지 | 물을 높이 9까지 올려 두는 물탱크 (+ 펌프) |
| 저항 (1kΩ) | 좁고 울퉁불퉁한 관 |
| LED와 저항 사이 지점 | 가운데 통 |
| 빨간 LED | 물이 지나가며 돌리는 물레방아 (높이 2쯤에서 열리는 문) |
| 전압 (V) | 물 높이 |
| 전류 (mA) | 1초에 지나가는 물방울 수 |

## 구성 (13개 장면, 약 8분)

1. **시작** – 오늘의 물길 소개
2. **무엇이 무엇?** – 그림 속 부품과 이름표
3. **물방울 수** – 저항 앞과 뒤의 전류가 왜 같은가
4. **뭐가 줄어?** – 저항을 지나면 줄어드는 것은 전압(높이), 잃은 힘은 열
5. **9, 2, 7** – 저항에 걸리는 전압 = 앞 높이 − 뒤 높이
6. **차이와 흐름** – 높이 차이가 클수록 많이 흐른다
7. **2는 누가 정해?** 🖐 – 가운데 통 물 높이를 직접 끌어 보며 평형점 찾기
8. **'너무 높으면'?** – 통이 낮으면 차오르고 높으면 내려가는 원리
9. **탱크를 높이면?** 🖐 – 건전지 전압(4~15V)을 바꿔 보기
10. **나란히 연결** 🖐 – 빨강·파랑 LED 병렬 연결 시 파란 LED가 꺼지는 이유
11. **따로 저항** 🖐 – LED마다 저항을 달면 둘 다 켜지는 이유, 저항값 조절
12. **빨강에 3V?** 🖐 – 빨간 LED를 3V로 만들려면 왜 불가능한지 계산해 보기
13. **정리** – 오늘 배운 여덟 가지

🖐 표시는 버튼·슬라이더·드래그로 직접 조작하는 장면입니다.

## 주요 기능

- **자동 재생 + 수동 이동**: 재생/멈춤, 이전·다음, 장면 칩으로 원하는 장면 바로 이동
- **읽어주기(TTS)**: 브라우저 음성 합성으로 한국어 설명을 읽어 줌
- **실시간 시뮬레이션**: LED의 전압-전류 특성(지수 곡선)을 이용해 가운데 통 물 높이가 평형점(약 2V, 7mA)으로 수렴하는 과정을 계산
- **다크 모드** 자동 대응, 모바일 화면 대응
- **키보드**: `Space`로 재생/멈춤
